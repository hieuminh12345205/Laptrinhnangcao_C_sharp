# Bài 2 — Quản lý hình học

Ngày làm: **12.09.2026**.

Ứng dụng Console C# quản lý hình tròn, hình chữ nhật và hình tam giác.

- Dùng interface `Hinh` và `List<Hinh>` để áp dụng tính đa hình.
- Nhập kích thước, tính diện tích và chu vi, hiển thị danh sách hình.
- Kiểm tra kích thước dương và điều kiện ba cạnh tạo thành tam giác.

Chạy từ thư mục gốc repository:

```powershell
dotnet run --project .\Bai_2\Bai_2.csproj
```
