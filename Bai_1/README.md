# Bài 1 — Nhập số và tính tổng

Ngày làm: **12.09.2026**.

Ứng dụng Console C# nhập ba số nguyên `a`, `b`, `c` và tính tổng `a + b + c`.
Chương trình dùng `int.TryParse` để kiểm tra và yêu cầu nhập lại khi dữ liệu không phải số nguyên.

Chạy từ thư mục gốc repository:

```powershell
dotnet run --project .\Bai_1\Bai_1.csproj
```
